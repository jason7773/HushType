# Hushtype 悄聲 Android 版

**重視隱私的語音輸入鍵盤。** 在任何 App 切換到 Hushtype 鍵盤，按一下麥克風說話，再按一下（或按住說話、放開）就會輸入去掉贅字、加好標點的繁體中文。錄音和文字只送到你自己選、自己申請金鑰的服務（Groq、OpenAI 或 Gemini）。

## 安裝

1. 在手機上打開 [Releases](https://github.com/jason7773/hushtype/releases)，找到最新的 **Hushtype Android**，下載 `Hushtype-android-x.y.z.apk`
2. 打開下載的檔案。第一次安裝時手機會要求允許「安裝未知應用程式」，允許後再按「安裝」
3. 打開 Hushtype，依照首頁「開始使用」的三個步驟：啟用鍵盤、允許麥克風、填入 API 金鑰
4. 在任何輸入框點右下角的鍵盤圖示（或通知列的「選擇輸入法」），切換到 Hushtype

系統需求：Android 11 以上。

## 使用

- **按一下**麥克風開始，**再按一下**結束；也可以**按住說話、放開結束**
- 錄音中按「取消」可以丟掉這次錄音；辨識失敗時錄音會保留，按「重試」即可
- 輸入後想反悔，按「復原」會刪掉剛剛那段文字
- 左上角開啟 Hushtype 設定；右上角切回原本的鍵盤（長按可選擇其他鍵盤）
- 下方有空白、刪除（按住連續刪除）與換行鍵，簡單修改不必切換鍵盤
- 設定裡可以打開「輸入後切回原本的鍵盤」，說完一段話自動回到平常用的鍵盤

## 功能

- **AI 整理**：去除贅字、處理說錯改口、加全形標點、長內容分段與條列
- **字典**：專有名詞（提示給辨識與整理模型）、固定替換（例如 `拍森 → Python`）
- **歷史紀錄**：預設只放在記憶體；選擇保留 1 天到永久時，用手機安全晶片裡的金鑰加密存在本機
- **使用洞察**：口述字數、節省時間、口述速度、連續天數與活躍日曆（只記數字，不記內容）
- **玻璃質感介面**：流動的極光背景，淺色／深色模式，可在設定關掉動態效果

## 隱私

- 錄音只放在記憶體，辨識完就丟掉，從不寫入儲存空間；鍵盤收起來時會立刻停止錄音
- API 金鑰用 Android Keystore 加密，金鑰無法匯出
- 關閉 Android 的雲端備份與換機搬移，金鑰、歷史紀錄與統計都不會離開這支手機
- 沒有自己的伺服器、沒有分析或廣告 SDK；只連到你在設定裡選的服務
- 啟用鍵盤時 Android 會顯示「此輸入法可能會收集你輸入的所有文字」，這是所有第三方鍵盤都會出現的標準警告。Hushtype 只會讀取「復原」需要比對的那段文字，不會讀取或記錄你打的其他內容

## 更新與簽章

之後的版本要能直接覆蓋安裝（保留設定），每一版都必須用同一把金鑰簽章。在 Windows 上雙擊 `packaging/setup-android-signing.bat`，依畫面把兩個 Secret 貼到 GitHub 即可。還沒設定前建置的 APK 用臨時金鑰簽章，安裝新版前要先解除安裝舊版。

## 開發

```
cd android
./gradlew testReleaseUnitTest assembleRelease
```

程式以 Kotlin 撰寫，不使用 AndroidX 或其他第三方函式庫，APK 很小。

- `core/`：錄音（`Recorder`）、WAV 與靜音修剪（`Wav`）、服務呼叫（`Providers`）、處理流程（`Dictation`）
- `data/`：設定、Keystore 加密、歷史紀錄、使用統計
- `ime/`：鍵盤（`HushtypeIme`）與麥克風按鈕
- `ui/`：App 畫面（首頁、字典、歷史、設定）與玻璃風格元件
